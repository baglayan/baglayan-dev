# Acouplet version 0.34 Early Alpha
## Release Notes

- You can now change the LDAC sample rate during playback.
- Improved LDAC handoff when switching between the Mac and a phone over multipoint.
- Added lighting, DJ, karaoke and Auracast controls for supported Sony speakers.
- Added equalizer, listening mode and sound optimization settings on supported headphones.
- Headphone status flyouts now appear at the top center in fullscreen. Supported Macs can show headphone status in the Dynamic Island.
- Fixed manual refresh after restoring Bluetooth permission.
